# Introduction to R 

This guide is suitable for new R\-users or advanced level R\-users looking for specific information. The topics covered in this guide are importing, exploring, modifying and managing data.

The main dataset used is the shelters dataset. It contains the Toronto daily shelter services from 2021 to 2026 \[1]. Resources are listed below. If you need assistance, fill out the [support request form](https://mdl.library.utoronto.ca/research/help).
